# SecYourFlow screenshots

This folder keeps the supplied full-screen app references for future design work. They are kept local because some screens contain account or workspace details.

The selected, presentation-safe crops used by the public marketing pages are in `public/screenshots/`. The asset inventory, remediation, and threat images show useful workspace sections rather than narrow header strips. The dashboard preview is explicitly labeled as sample data on the home page.

- `asset-inventory-section.png` — asset inventory summary, filters, list, and breakdown panels
- `cve-search-workspace.png` — CVE search results
- `cve-affected-products.png` — affected product/version table
- `remediation-plans-section.png` — remediation status, search, and plan list
- `threat-intelligence-section.png` — threat metrics, workspace tabs, and overview panels
- `nis2-governance.png` — NIS2 coverage and checklist
- `ai-assist-controls.png` — AI settings and human review controls
- `vulnerability-ai-assessment.png` — asset selection and AI risk assessment cue
- `vulnerability-form.png` — manual vulnerability workflow

The full references stay out of the public assets so profile details and empty/error-state data are not exposed.
